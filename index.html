Marketing skills you can install in one minute.

Curiosity Gap Hooks

First lines for LinkedIn, email, articles, video and ads that make the reader read the next line.

Writing · 5 variants

How to use any skill

  1. Install. Copy the skill folder into ~/.claude/skills/ (all projects) or .claude/skills/ (one project). Start a new Claude Code session.
  2. Describe the job. Say what you want in plain words. The skill triggers from the description. You can also name it: /skill-name.
  3. Give the three inputs. The format, the reader, and the true result you want the piece to deliver.
  4. Check the output. Each skill lists the checks to run before you publish. Do those, then use it.

Install example

mkdir -p ~/.claude/skills/curiosity-gap-hooks
cp skills/curiosity-gap-hooks/SKILL.md ~/.claude/skills/curiosity-gap-hooks/SKILL.md

Add a skill to this library

Make a folder under skills/ with a SKILL.md, a README.md that shows how to use it with good and bad examples, and a hero.webp thumbnail. Then add a card above.

Skills are free to copy and adapt. Check each skill's README for its source and license.
